<Warning>
  **Fanout has been retired** as of Dax 2.33.0. Saved Fanout profiles have
  been carried over to [Herdr](/tools/herdr) projects automatically.
</Warning>

Fanout opened a terminal in each of your repos with your coding agent
already running, tiled side by side. This functionality is now part of
[Herdr](/tools/herdr), which does everything Fanout did and adds tabs, a
sidebar, split-by-drag, and remote server support over SSH.

## Migrating

Your existing Fanout profiles are imported into Herdr automatically on
first launch after the update. No action needed.

See the [Herdr docs](/tools/herdr) for the full guide.
