**Open Project** shows you every project you've worked on with a coding
agent. Pick one to jump straight back into it — in your editor, your
terminal, or Dax Shepherd. Works fully offline.

</Frame>

## Open it

Press <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>O</kbd> from any app.

## How it works

<Steps>
  <Step title="Open the palette">
    Press <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>O</kbd>. A list of **every project
    you've used Claude Code or Codex in** floats up.
  </Step>
  <Step title="Pick an action">
    Use <kbd>⇥</kbd> or <kbd>←</kbd> <kbd>→</kbd> to walk between three
    tabs at the top:

    - **Open Folder** — opens the project in your editor or file manager.
    - **Open Coding Agent** — opens your terminal in that folder with the
      agent already running. <kbd>⇧</kbd> <kbd>⇥</kbd> switches which agent.
    - **Open Shepherd** — starts a new group of agents in Shepherd on
      **this Mac**. Every open is a new group. To run agents on a server
      instead, add the host inside Shepherd.
  </Step>
  <Step title="Pick a project">
    Press <kbd>↩</kbd> on the project you want.
  </Step>
</Steps>

<Tip>
  Pair it with [Frequent CLIs](/tools/frequent-clis): open the project, then
  jump to the CLI you run it with.
</Tip>

## Privacy

Local. Built from the same on-disk agent traces as [Vibe
History](/tools/vibe-history).
