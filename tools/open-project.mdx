**Open Project** is a palette of every project you've run a coding agent in —
pick one to reopen it in your editor or terminal. Works fully offline.

## Open it

Press <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>O</kbd> from any app.

## How it works

<Steps>
  <Step title="Open the palette">
    Press <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>O</kbd>. A list of **every project
    you've used Claude Code or Codex in** floats up.
  </Step>
  <Step title="Pick a project">
    Select the one you want to jump into.
  </Step>
  <Step title="Choose how to open it">
    It **opens in your chosen terminal/editor**, either as a **fresh
    session** or **resuming your last conversation** there.
  </Step>
</Steps>

<Tip>
  Pair it with [Frequent CLIs](/tools/frequent-clis): open the project, then
  jump to the CLI you run it with.
</Tip>

## Privacy

Local. Built from the same on-disk agent traces as [Vibe
History](/tools/vibe-history).
