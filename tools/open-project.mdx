**Open Project** takes you right into a project without digging through Finder or
your editor's recent list. Pick the project, and Dax opens it.

## Open it

Choose **Open Project** from the Dax menu bar.

## Use it

<Steps>
  <Step title="Open the picker">
    Choose Open Project from the menu.
  </Step>
  <Step title="Choose a project">
    Select the one you want to jump into.
  </Step>
  <Step title="Get to work">
    Dax opens it for you.
  </Step>
</Steps>

<Tip>
  Pair it with [Frequent CLIs](/tools/frequent-clis): open the project, then jump
  to the CLI you run it with.
</Tip>

## Great for

- Switching between the projects you work on daily
- Getting back into a codebase without the click-through
- Starting a session in one step
