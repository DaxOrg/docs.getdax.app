**Frequent CLIs** is a searchable list of the commands you use most often.
Pick one and it types it into the app you're using, or opens a new terminal
window with the command ready to go. No more retyping.

## Open it

Press <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>↩</kbd> from any app.

## How it works

<Steps>
  <Step title="Focus your target">
    Focus wherever you want the command to go: a terminal, an editor, a chat
    box.
  </Step>
  <Step title="Open the palette">
    Press <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>↩</kbd>. Your saved commands float up
    as a list.
  </Step>
  <Step title="Pick one">
    Choose with the arrow keys or a click. The command is **typed into the
    focused app**, exactly as if you'd keyed it yourself.
  </Step>
</Steps>

## Two modes (press Tab to switch)

- **Insert** (default): types the command into the focused app.
- **Open in Terminal:** opens a fresh terminal in your **default folder** and
  runs the command there. Great for `claude`, `codex`, or a dev server you want
  in its own window.

<Tip>
  **Insert-and-run.** Mark a command with the <kbd>↩</kbd> badge and Frequent
  CLIs presses Return for you after inserting it, so a one-keystroke summon can
  launch a build, a deploy, or a dev server outright.
</Tip>

## Configuring commands

Settings → Tools → Frequent CLIs:

- Add as many commands as you like, each with a **Title**, the **Command**
  text, and a chosen **icon**. Click ✎ (or double-click a row) to edit, drag
  to reorder, or press <kbd>⌘</kbd><kbd>E</kbd> from the palette to edit the
  highlighted command.
- Toggle the per-command **insert-and-run** (<kbd>↩</kbd>) behavior.
- **Open in Terminal, default folder:** the directory that mode starts in.
- **Also skip Claude's folder-trust prompt on YOLO launches:** when a command
  runs `claude --dangerously-skip-permissions`, Dax marks the folder trusted in
  `~/.claude.json` (a backup is saved first) so Claude drops straight in
  instead of showing its trust banner. Off shows the normal one-time prompt.

## Privacy

Entirely local. Your commands are stored on your Mac and either typed into the
focused app or run in a terminal you opened. They never leave the machine.
