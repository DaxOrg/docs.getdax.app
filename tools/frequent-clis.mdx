**Frequent CLIs** is a summonable palette of the commands you type all day,
dropped into whatever app is focused so you never retype them. Works fully
offline.

## Open it

Press <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>↩</kbd> from any app.

## How it works

<Steps>
  <Step title="Focus your target">
    Focus wherever you want the command to go — a terminal, an editor, a chat
    box.
  </Step>
  <Step title="Open the palette">
    Press <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>↩</kbd>. Your saved commands float up
    as a list.
  </Step>
  <Step title="Pick one">
    Choose with the arrow keys or a click. The command is **typed into the
    focused app**, exactly as if you'd keyed it yourself.
  </Step>
</Steps>

<Tip>
  **Insert-and-run.** Mark a command with the <kbd>↩</kbd> badge and Frequent
  CLIs presses Return for you after inserting it — a one-keystroke summon can
  launch a build, a deploy, or a dev server outright.
</Tip>

## Configuring commands

Settings → Tools → Frequent CLIs:

- Add as many commands as you like, each with a **Title**, the **Command**
  text, and a chosen **icon**.
- Toggle the per-command **insert-and-run** (<kbd>↩</kbd>) behavior.

## Privacy

Entirely local. Your commands are stored on your Mac and typed directly into
the focused app — they never leave the machine.
