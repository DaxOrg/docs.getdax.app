**Inject MD** drops a Markdown instruction file (like `AGENTS.md`) into any
project you've worked in, right where the coding agent will read it. Works
fully offline.

<Frame>
  <img src="/images/screenshots/inject-md.jpg" alt="Inject MD — choose a file to inject" />
</Frame>

## Open it

Press <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>A</kbd> from any app.

## How it works

<Steps>
  <Step title="Pick the file">
    Press <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>A</kbd>, then pick which Markdown
    file to inject (`AGENTS.md` by default).
  </Step>
  <Step title="Pick a project">
    A palette of **every project you've run Claude Code or Codex in**
    appears, distilled from your session traces.
  </Step>
  <Step title="Inject">
    Pick a project. The file is **written into that project's folder**,
    exactly where the agent looks for it.
  </Step>
</Steps>

## Share as a link

Instead of injecting into a local folder, choose **Share as a link** from
the top of the project palette. The file uploads and you get a URL that any
remote agent (or Herdr server) can fetch with `curl`.

- **Expiry:** links expire after a set period (default 7 days, configurable
  up to 30 days).
- **Manage links:** view and revoke published links from the same screen.

<Tip>
  PRD Maker also uses this link infrastructure to share finished PRDs with
  remote agents.
</Tip>

## Privacy

Local by default. The project list comes from on-disk traces; the file is
written locally. Sharing as a link is the one action that sends the file
off your Mac.
