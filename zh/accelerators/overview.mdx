Accelerators 内置于 Dax。每个 Accelerator 只做一件事，而这些事原本会让你中断
手头的工作：把截图变成链接、快速问一个问题、把密钥交给 Agent、录一段片段。它们
在你当前所用的应用之上打开，完成任务，然后让开。

它们与[主窗口](/zh/main-window)（你的编程 Agent 运行的地方）以及手机上的
[Dax Companion](/zh/companion) 同属一个平台。许多 Accelerator 也为你的 Agent
所用：Dax 里的 Agent 可以把文件放到你的 [Shelf](/zh/accelerators/shelf) 上、
在你的屏幕上做标注，或者向你索取一个[密钥](/zh/accelerators/secrets)，而永远
看不到它的值。

## 打开方式

- **它的快捷键。** 每个 Accelerator 都有一个全局快捷键，默认是 <kbd>⌃</kbd>
  <kbd>⌥</kbd> 加一个按键。[快捷键页面](/zh/shortcuts)列出了全部快捷键。
- **启动器。** 按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>Space</kbd>，打开一个可搜索
  的网格，里面是每一个 Accelerator。点击一个，或按 <kbd>1</kbd>–<kbd>9</kbd>
  选择前九个。
- **菜单栏。** 点击 Dax 图标，也能在那里找到它们。

## 按你的方式定制

- **关闭某个 Accelerator**：在 **设置 → Accelerators**（<kbd>⌃</kbd>
  <kbd>⌥</kbd> <kbd>T</kbd>）中操作。关闭后的 Accelerator 不再响应快捷键，也会
  从启动器中消失。
- **重新绑定快捷键**：在 **设置 → Shortcuts**（<kbd>⌃</kbd> <kbd>⌥</kbd>
  <kbd>H</kbd>）中操作。
- **整理启动器。** 选择 **Arrange Accelerators…**，把它们拖成你自己的顺序，并
  置顶最常用的几个；也可以按最常用、最近使用或 A–Z 排序。

## 自己动手做一个

用 JavaScript 编写自定义 Accelerator，Dax 会用原生 macOS 控件把它绘制出来。它
和内置的 Accelerator 一样可以从启动器打开，你也可以为它设置专属快捷键。参见
[Accelerator SDK](/developers/accelerator-sdk)。

<Note>
  自定义 Accelerator 适用于从 getdax.app 下载的 Dax。Setapp 版 Dax 只运行内置的
  Accelerator。
</Note>
