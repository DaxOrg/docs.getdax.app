**Screen Markup** 让你直接在屏幕上绘制：箭头、方框、高亮、标签、标尺，以及真正的
模糊。按下 <kbd>⌘</kbd> <kbd>Return</kbd>，标注后的截图就会出现在一张卡片里，已经
上传完毕，随时可以分享。

## 打开方式

在任意应用中按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>M</kbd>。

Screen Markup 需要**屏幕录制**权限。Dax 会在第一次使用时请求该权限。

## 使用方法

<Steps>
  <Step title="绘制">
    屏幕会被捕获，顶部出现一个工具栏。选择一个绘图工具开始绘制。拖动工具栏的
    把手可以把它移开。
  </Step>
  <Step title="完成">
    按下 <kbd>⌘</kbd> <kbd>Return</kbd>，或点击 **Finish**。按 <kbd>Esc</kbd>
    取消。
  </Step>
  <Step title="分享">
    结果会以卡片形式出现在角落里。可以把它拖到任意位置，上传完成后复制它的链接，
    或重新打开它再次标注。
  </Step>
</Steps>

## 冻结或实时

- **Frozen** 在你绘制时让画面保持静止。
- **Live** 让画面在你的标注下方持续更新。

两种模式下应用都会继续运行。用工具栏中的 **Frozen** / **Live** 按钮切换。

## 绘图快捷键

| 工具 | 按键 |
| --- | --- |
| 选择 | <kbd>V</kbd> |
| 画笔 | <kbd>P</kbd> |
| 荧光笔 | <kbd>H</kbd> |
| 箭头 | <kbd>A</kbd> |
| 方框 | <kbd>B</kbd> |
| 模糊 | <kbd>R</kbd> |
| 标签 | <kbd>T</kbd> |
| 标尺 | <kbd>M</kbd> |
| 撤销 / 重做 | <kbd>⌘</kbd> <kbd>Z</kbd> / <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> |
| 删除选中的标注 | <kbd>Delete</kbd> |
| 完成 | <kbd>⌘</kbd> <kbd>Return</kbd> |
| 取消 | <kbd>Esc</kbd> |

在工具栏中选择颜色和线条粗细（细、中或粗）。

## 设置

在 **设置 → Accelerators → Screen Markup** 中可以找到：

- **Start in** —— 冻结或实时屏幕。
- **Display** —— 指针所在的显示器、主显示器，或指定的某一个。
- **Starting drawing tool** —— 打开时默认选中的绘图工具。
- **Upload the annotated screenshot** —— 默认开启。上传使用你的存储设置。
- **Keep a copy in Pictures › Dax Shots › Screen Markup** —— 默认开启。
- **Copy the image immediately** —— 默认关闭。

**Show all results** 列出每一次标注，提供 **Retry upload**、**Copy link** 和
**Remove**。结果保存在你的 Mac 上。因重新启动而中断的上传会等待你重试。

## 供 Agent 使用

编程 Agent 通过 `dax-screen-markup` MCP 服务器在你的实时屏幕上指出内容、捕获带有
标注的屏幕，或打开 Screen Markup 并放好它们的标注、等待你的标注。最后一种就是
Agent 请你「指给我看」的方式。
