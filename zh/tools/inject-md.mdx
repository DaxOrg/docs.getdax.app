**Inject MD** 会把一份 Markdown 指令文件（比如 `AGENTS.md`）放进你用过的任意
项目，正好放在编程 Agent 会读取到的位置。完全离线可用。

## 打开方式

在任意应用中按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>A</kbd>。

## 使用方法

<Steps>
  <Step title="选择文件">
    按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>A</kbd>，然后选择要注入的 Markdown
    文件（默认是 `AGENTS.md`）。
  </Step>
  <Step title="选择项目">
    一份面板会出现，列出**你用过 Claude Code 或 Codex 的所有项目**，数据来自
    你的会话记录。
  </Step>
  <Step title="注入">
    选中一个项目，文件会被**写入该项目的文件夹**，正好是 Agent 会去查找的
    位置。
  </Step>
</Steps>

## 以链接分享

不注入到本地文件夹，而是从项目面板顶部选择 **Share as a link**。文件会上传，
你会得到一个 URL，任何远程 Agent（或 Herdr 服务器）都可以用 `curl` 获取。

- **过期时间：** 链接在一段时间后过期（默认 7 天，可配置至 30 天）。
- **管理链接：** 在同一界面查看和撤销已发布的链接。

<Tip>
  PRD Maker 也使用这个链接基础设施来与远程 Agent 分享已完成的 PRD。
</Tip>

## 隐私

默认本地运行。项目列表来自本地记录，文件写入也在本地完成。以链接分享是唯一
会将文件发送到你 Mac 之外的操作。
