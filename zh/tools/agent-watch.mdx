**Agent Watch** 替你盯着 Claude Code 会话。当某个会话完成或需要你的关注时，
它会立即通知你，并让你直接跳转过去，或者在通知气泡中直接回复而无需切换应用。

一切都在你的 Mac 上运行。

## 打开方式

在任意应用中按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>M</kbd>。

## 使用方法

<Steps>
  <Step title="运行你的 Agent">
    在任意终端（Terminal、iTerm 或 Ghostty）中启动一个或多个 Claude Code 会话。
    Agent Watch 会自动检测到它们。
  </Step>
  <Step title="继续工作">
    当某个会话完成或在等你时（权限提示、提问），会弹出一个通知气泡。点击气泡
    跳转到对应终端，或直接在气泡中输入回复。
  </Step>
  <Step title="打开面板">
    按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>M</kbd> 一览所有实时会话。每一行显示
    项目名称、Agent 最后说了什么、状态指示灯以及处于该状态的时长。按
    <kbd>↩</kbd> 跳转到选中的会话。
  </Step>
</Steps>

## 会话状态

每个会话处于三种状态之一：

| 状态 | 指示灯 | 生物 | 含义 |
|---|---|---|---|
| **工作中** | 🟢 绿色 | 行走 | Agent 正在输出内容或某个工具正在运行。 |
| **等你操作** | 🟡 黄色 | 来回挪动 | 工具调用沉默了足够长的时间，看起来像是权限提示。 |
| **已完成** | ⚫ 灰色 | 静止不动 | Agent 已交还控制权。轮到你了。 |

状态指示灯和生物动画表达的是同一个信息，所以你可以一眼扫过面板，无需停下来
阅读文字。

## 角色

每个项目都有自己的像素小生物，由其文件夹路径决定。同一个仓库，同一个角色，
每次都是。屏幕上不会有两个一样的会话。

当两个或多个会话共享同一个文件夹时，它们会在头像角落和名称中标上编号
（"Dax 1"、"Dax 2"），这样你总能分辨它们。

它们在会话工作时行走，在等你操作时来回挪动，完成后静止不动。

## 从通知气泡中回复

当某个会话在等你时，通知气泡中包含一个文本框。输入回复然后按 Return。Dax 会
找到运行该会话的终端，将其前置，并粘贴你的回复。支持 Terminal、iTerm 和
Ghostty。

如果无法识别终端，回复会放到剪贴板上，并提示你手动粘贴。

## Hooks（可选，推荐）

没有 hooks 时，Dax 每隔几秒读取 Agent 的 trace 文件来*推断*它是否在等待。
安装 hooks 后，Claude Code 会直接告诉 Dax，速度更快且准确无误。

在 **Settings → Tools → Agent Watch → Install Hooks** 中安装。这会在
`~/.claude/settings.json` 中添加两个条目（会先备份）：

- **Notification：** 在会话遇到权限提示或完成的瞬间触发。
- **Stop：** 在最终回复出来时送达。

Remove Hooks 只会移除 Dax 的条目，其他内容保持不变。

## 自然语言摘要

Agent 写的是段落，通知气泡只有一行的空间。开启 **Say it in plain language**
后，Dax 会用 Apple 的设备端模型将 Agent 的消息改写为一句话，无需联网、无费用、
离线可用。需要 macOS 26 和 Apple Intelligence。

## 选项

Settings → Tools → Agent Watch：

- **A session finishes：** 一个回合完成时弹出通知。
- **One is waiting on me：** 遇到权限提示或提问时弹出通知。
- **Play a sound：** 在通知的同时播放提示音。
- **Pause watching：** 暂停通知而不禁用工具。
- **Say it in plain language：** 使用设备端 AI 生成 Agent 消息的摘要。
- **Let me answer from the toast：** 在"等你操作"的通知中显示回复框。

## 隐私

完全在你的 Mac 上运行。Agent Watch 读取 Claude Code 已写入磁盘的 trace 文件，
从不联网。可选的摘要使用 Apple 的设备端模型，你的代码不会离开本地。

## 支持的 Agent

目前仅支持 Claude Code。Codex 会写入 Dax 可以读取的 trace 文件，但没有 hook
来直接报告状态，所以其会话暂不被监控，而非半支持。
