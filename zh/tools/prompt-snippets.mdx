**Prompt Snippets** 提供一个可搜索的已保存提示词面板，按一下快捷键即可将可
复用的文本块输入或粘贴到任何应用中。完全在设备上运行。

## 打开方式

在任意应用中按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>J</kbd>。

## 使用方法

<Steps>
  <Step title="打开面板">
    按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>J</kbd>，你保存的片段以可搜索的列表
    浮现。
  </Step>
  <Step title="搜索并选择">
    输入关键词筛选，然后按 <kbd>↩</kbd> 使用选中的片段。<kbd>⇥</kbd> 可在
    复制到剪贴板和直接输入到当前聚焦应用之间切换。
  </Step>
  <Step title="管理片段">
    在 **Settings → Tools → Prompt Snippets** 中添加、编辑或删除片段。Dax
    自带一组内置片段帮你入门。
  </Step>
</Steps>

## 提示

- 片段完全保存在你的 Mac 上，不会发送到任何服务器。
- 用片段保存系统提示词、代码审查清单、提交模板，或任何你经常要用的文本块。
- <kbd>⇥</kbd> 切换会在当前会话中记住你的上次选择。
