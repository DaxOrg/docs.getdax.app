**Vibe History** 是一个面板，收录你最近与 Claude Code 和 Codex 的对话，直接
读取自它们在本地留下的记录文件——选中一个即可继续。

## 打开方式

在任意应用中按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>S</kbd>。

## 使用方法

<Steps>
  <Step title="打开面板">
    按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>S</kbd>，你最近的 Agent 对话会以
    列表形式浮现。
  </Step>
  <Step title="选择一段对话">
    选中你想恢复的那一段。
  </Step>
  <Step title="继续对话">
    对应对话的**恢复命令**会被**输入到你所在的终端**，让你直接回到之前
    离开的地方。
  </Step>
</Steps>

## 选项

设置 → Tools → Vibe History：

- 切换要包含哪些 Agent：**Claude Code**、**Codex**。

## 隐私

本地运行。它读取的是这些 Agent 本就会写在你 Mac 上的记录文件，不会把任何
内容发送出去。
