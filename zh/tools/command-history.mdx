**Command History** 是一个可模糊搜索的面板，收录你在各种 Shell（zsh、bash、
fish、sh、ksh、tcsh）中执行过的所有命令。选中一条，它会被输入到当前聚焦的
终端，也可复制，或在新窗口中打开。100% 本地且只读，任何内容都不会离开你的
Mac。

## 打开方式

在任意应用中按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>Y</kbd>。

## 使用方法

<Steps>
  <Step title="聚焦终端">
    聚焦你想输入命令的终端（或任意文本框）。
  </Step>
  <Step title="打开面板">
    按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>Y</kbd>，你的历史命令按使用频率排序
    浮现，最常用的命令排在最前面。
  </Step>
  <Step title="搜索并选择">
    输入文字进行模糊搜索。按 <kbd>↩</kbd> 执行选中的命令，
    <kbd>⌘</kbd><kbd>↩</kbd> 插入并运行，<kbd>⌘</kbd><kbd>C</kbd> 复制。
  </Step>
</Steps>

<Tip>
  **实时切换 ↩ 的行为。** 按 <kbd>⌘</kbd><kbd>T</kbd>（或点击模式按钮）在
  **插入**到当前终端、在**新终端**中打开、或**复制**之间循环切换，设置会在
  各次使用间保留。
</Tip>

## 安全性

看起来具有破坏性的命令（`rm -rf`、`sudo`、`dd`……）会被插入供你审查，但
**绝不会自动运行**，即使使用 <kbd>⌘</kbd><kbd>↩</kbd> 或开启了"按回车即
运行"设置也是如此。

## 配置

设置 → Tools → Command History：

- **Shell**：选择要搜索哪些 Shell（默认包含你 Mac 上所有有历史记录文件的
  Shell）。
- **Start with**：在搜索栏预填一个前缀（如 `ssh`），将面板变为某类命令的
  专用启动器。
- **Only show commands matching**：正则过滤器；默认（`^\S+\s+\S+`）只保留
  "命令 + 参数"形式的行。
- **Hide these commands**：逗号分隔的排除列表，用于隐藏不需要的命令
  （`ls`、`cd`、`clear`...）。
- **Run on ↩**：开启后，<kbd>↩</kbd> 会在插入后按下回车（默认关闭；破坏性
  命令仍然绝不自动运行）。

## 隐私

完全本地。你的 Shell 历史文件只会被读取（不会被写入），任何内容都不会离开
你的设备。
