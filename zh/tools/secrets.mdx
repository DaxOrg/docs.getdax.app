**Secrets** 让你把 API Key 或密码交给编程 Agent，**无需在对话中粘贴明文值**。
你只需存储一次密钥；Dax 会给 Agent 一行指令，并仅在你批准后，把真实值注入到
需要它的那一条命令中。完全离线可用。

## 打开方式

在任意应用中按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>V</kbd>。

## 使用方法

<Steps>
  <Step title="打开面板">
    按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>V</kbd>，Secrets 面板浮现。
  </Step>
  <Step title="添加密钥">
    输入一个**名称**（支持常用名称的自动补全）和**值**。值会存储在 Mac 的
    **钥匙串**中；你可以在输入框里切换显示/隐藏。
  </Step>
  <Step title="粘贴指令">
    Dax 会给你一行**可直接粘贴的命令**，例如
    `dax run --secret OPENAI_API_KEY -- <your command>`。
  </Step>
  <Step title="批准注入">
    当 Agent 执行该命令时，本地的 **Dax broker** 会要求你**批准**。批准后，
    真实值只会被注入到*这条命令*的环境中，不会被打印，也不会存储在聊天记录里。
  </Step>
</Steps>

<Tip>
  **为什么安全。** 值存储在钥匙串中，仅在你明确批准后通过 broker 释放给单条
  命令。它不会出现在对话、终端回滚缓冲区或任何日志中。
</Tip>

## 隐私

完全本地运行。broker 在你的 Mac 上运行，密钥从不离开设备。
