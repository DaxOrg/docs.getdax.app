**Markdown 查看器** 使用 Dax 自有的 Markdown 解析器和渲染器打开 `.md` 文件——表格、嵌套列表、任务列表、引用块、脚注和代码块都按文档原意呈现。你可以在同一窗口中编辑和保存。

## 打开方式

在任意应用中按 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>R</kbd>。

## 使用方法

<Steps>
  <Step title="选择文件">
    从文件选择器中选择一个 `.md` 文件，或从 Finder 打开。
  </Step>
  <Step title="阅读">
    文档将完整渲染：标题、列表、表格、代码块（语法高亮）、图片、视频、引用块、脚注和任务列表。
  </Step>
  <Step title="编辑">
    修改文档并保存。查看器是一个工作空间，而非只读预览。
  </Step>
</Steps>

## 快速预览

Dax 附带快速预览扩展。在 Finder 中对任意 `.md` 文件按**空格键**，即可获得相同的渲染视图。

## 隐私

所有操作在本机完成，文件内容不会离开设备。
