**File Drop** 能把任意文件或文件夹变成一个分享链接，把一整批上下文交给 LLM
的最快方式。

## 打开方式

在任意应用中按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>L</kbd>。或者跳过快捷键：
**摇晃**你正在拖拽的文件，指针下方会出现一个拖放架。

## 使用方法

<Steps>
  <Step title="打开拖放窗口">
    按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>L</kbd>，一个拖放窗口会浮现，并且
    **在你从 Finder 拖拽时保持显示**。
  </Step>
  <Step title="拖入文件">
    **单个文件**会**原样**上传。**多个文件或一个文件夹**会先打包成**一个
    压缩包**，再上传。
  </Step>
  <Step title="上传">
    点击**上传**，**链接会出现在你的剪贴板**，可以粘贴给任意 LLM。
  </Step>
</Steps>

## 摇晃拖放

在任意位置拿起文件，保持按住的同时**左右摇晃**，指针下方会出现一个深色拖放架。
放到上面，上传立即开始 —— 无需按 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>L</kbd>。

- **默认开启**，首次使用时会有一个说明提示
- 在 **Settings → Tools → File Drop → Shake to drop** 中关闭
- 三次快速的水平方向反转即可触发拖放架

<Tip>
  在 Finder 中选中多个文件一起拖入。File Drop 会把它们当作一批处理。
</Tip>

## 限制与说明

- 单次上传上限为 **256 MB**。
- 链接**会在 90 天后自动过期**。
- **文件只会在你点击「上传」时离开这台 Mac**，拖入时不会。
- 关闭窗口不再取消上传 —— 上传会在后台继续。
