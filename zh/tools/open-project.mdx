**Open Project** 是一个面板，列出你曾用编程 Agent 处理过的每一个项目。选中
一个即可在编辑器或终端中重新打开。完全离线可用。

## 打开方式

在任意应用中按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>O</kbd>。

## 使用方法

<Steps>
  <Step title="打开面板">
    按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>O</kbd>，一份列出**你用过 Claude
    Code 或 Codex 的所有项目**的列表会浮现。
  </Step>
  <Step title="选择一个项目">
    选中你想要跳转的那一个。
  </Step>
  <Step title="选择打开方式">
    它会在你选定的终端或编辑器中打开，可以是**全新会话**，也可以**恢复你在
    那里最后一次的对话**。
  </Step>
</Steps>

<Tip>
  搭配 [Frequent CLIs](/zh/tools/frequent-clis) 使用：打开项目后，直接跳转
  到你用来运行它的命令行。
</Tip>

## 隐私

本地运行，基于与 [Vibe History](/zh/tools/vibe-history) 相同的本地 Agent
记录构建。
