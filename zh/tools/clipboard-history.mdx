**Clipboard History** 保留一份你复制过的所有内容（文本、图片和文件）的可搜索
记录，按一下快捷键就能找回其中任何一项。完全在设备上运行。

## 打开方式

在任意应用中按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>C</kbd>。

## 使用方法

<Steps>
  <Step title="像往常一样复制">
    每次你复制（⌘C）时，Dax 会静默地将该项保存到你的本地历史中。
  </Step>
  <Step title="打开面板">
    按下 <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>C</kbd>。你最近复制的内容以可搜索的
    列表显示，选中项有完整预览。
  </Step>
  <Step title="重新粘贴">
    按 <kbd>↩</kbd> 将选中项放回剪贴板，随时粘贴到任何地方。
  </Step>
</Steps>

## 静默复制指示

复制内容时，菜单栏图标会短暂变成一个向下的箭头，而不是播放声音。提示音默认
关闭；如果你更喜欢有声提示，可以在 **Settings → Tools → Clipboard History**
中重新开启。

## 提示

- 你的剪贴板历史完全保存在 Mac 上，不会上传到任何地方。
- 支持文本、图片和文件。
- 被密码管理器标记为隐藏的复制项不会被记录。
- 输入关键词即可搜索所有复制项。
- 可在 **Settings → Tools → Clipboard History** 中配置历史记录大小。
