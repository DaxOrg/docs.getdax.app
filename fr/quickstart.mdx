Dax s'execute depuis votre barre de menu et reste discret jusqu'a ce que
vous appuyiez sur un raccourci. Ce guide vous accompagne du telechargement
jusqu'a votre premier resultat.

## Prerequis

- Un Mac sous macOS 14 (Sonoma) ou version ulterieure
- Apple Silicon ou Intel (les deux fonctionnent)

## Etape 1 : Telecharger et installer

<Steps>
  <Step title="Telecharger Dax">
    Rendez-vous sur [getdax.app/download](https://getdax.app/download/). Le
    programme d'installation se telecharge automatiquement.
  </Step>
  <Step title="Lancer le programme d'installation">
    Ouvrez le fichier `.pkg` telecharge et suivez les instructions. Dax
    s'installe dans votre dossier Applications.
  </Step>
  <Step title="Ouvrir Dax">
    Lancez Dax depuis Applications. Une petite icone apparait dans votre
    **barre de menu** en haut de l'ecran. C'est votre point de depart.

    <Tip>
      Si macOS vous demande « Voulez-vous vraiment ouvrir cette
      application ? », cliquez sur **Ouvrir**. Dax est signe et notarie
      par Apple.
    </Tip>
  </Step>
</Steps>

## Etape 2 : Configurer votre compte

La premiere fois que vous ouvrez Dax, un ecran de configuration vous guide
a travers la creation d'un compte :

<Card title="Creer un compte Dax" icon="user-plus">
  Entrez votre nom et votre e-mail. Nous vous envoyons un code ;
  saisissez-le et votre compte s'active instantanement. Commencez avec le
  plan Free et passez au plan Pro a tout moment.
</Card>

<Note>
  **Vous avez deja un code ?** Appuyez sur « Already have a code? » sur
  l'ecran de configuration et saisissez-le directement.
</Note>

## Etape 3 : Essayer votre premier outil

Transformons une image en lien partageable avec
[Image to URL](/fr/tools/image-to-url).

<Steps>
  <Step title="Copier une image">
    Faites une capture d'ecran (<kbd>⌘</kbd><kbd>⇧</kbd><kbd>4</kbd>) ou
    copiez n'importe quelle image dans votre presse-papiers.
  </Step>
  <Step title="Appuyer sur le raccourci">
    Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>U</kbd> depuis n'importe ou.
    C'est **Control + Option + U**.
  </Step>
  <Step title="Obtenir le lien">
    Dax envoie l'image et copie une URL partageable dans votre
    presse-papiers. Collez-la ou vous en avez besoin : un chat, une pull
    request, un document.
  </Step>
</Steps>

<Tip>
  **Pas sur des raccourcis ?** Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd>
  <kbd>Space</kbd> (Control + Option + Espace) pour ouvrir la **grille du
  lanceur** ou chaque outil est a un clic. Vous pouvez aussi cliquer sur
  l'icone Dax dans votre barre de menu.
</Tip>

<Note>
  **Qu'est-ce qu'un raccourci ?** C'est une combinaison de touches que vous
  appuyez pour ouvrir instantanement un outil. Dans Dax, la plupart des
  raccourcis sont **Control + Option + une lettre**. Vous maintenez Control
  et Option ensemble, puis appuyez sur la lettre. Par exemple,
  <kbd>⌃</kbd><kbd>⌥</kbd><kbd>K</kbd> signifie maintenez Control + Option,
  puis appuyez sur K.
</Note>
