**Generate Image** crée une toute nouvelle image à partir d'une
description, ou modifie une photo que vous fournissez — le tout depuis un
panneau flottant, entièrement au clavier.

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>G</kbd> depuis n'importe quelle
app.

## Fonctionnement

<Steps>
  <Step title="Choisissez un modèle">
    Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>G</kbd>. Une rangée de
    modèles apparaît — choisissez avec <kbd>←</kbd> <kbd>→</kbd> (ou
    <kbd>1</kbd>–<kbd>3</kbd>) et confirmez avec <kbd>↩</kbd>.
  </Step>
  <Step title="Choisissez un mode">
    <kbd>⇥</kbd> bascule entre les modes :
    - **Create new** — crée une image à partir de vos mots.
    - **Edit a photo** — modifie une photo que vous ajoutez. Joignez
      jusqu'à **10** photos de référence via **Choose Photo**, **Snip
      Screen**, <kbd>⌘</kbd> <kbd>V</kbd>, ou par glisser-déposer.
  </Step>
  <Step title="Générez">
    Tapez votre description, ajustez le format ou l'arrière-plan si vous
    voulez, et appuyez sur <kbd>↩</kbd> pour générer.
  </Step>
  <Step title="Utilisez le résultat">
    Le résultat apparaît **dans le panneau**, le **lien hébergé est copié
    automatiquement**, et le **fichier est enregistré automatiquement sur
    votre Desktop**. Le coût réel de cette image est affiché.
  </Step>
</Steps>

## Modèles

**OpenAI**, **Nano Banana**, **Seedream**.

## Formats d'image

Auto · Square (1:1) · Wide (16:9) · Tall (9:16) · Landscape (4:3) ·
Portrait (3:4) · Social (4:5) · Frame (5:4).

## Arrière-plan

Auto · Transparent · Opaque.

## Historique

<kbd>⌘</kbd> <kbd>H</kbd> affiche vos **50 dernières générations** —
appuyez sur <kbd>↩</kbd> sur l'une d'elles pour la récupérer. Le panneau se
souvient de l'endroit où vous l'avez déplacé.

## Options

Settings → Tools → Generate Image :

- **Une fois l'image prête, copier** — *le lien* ou *l'image elle-même*
  (le fichier est de toute façon enregistré sur votre Desktop).
- **Modèle**, **format** et **arrière-plan** par défaut.

<Tip>
  Vous ne savez pas comment formuler un prompt ? Partez de [Image to
  Prompt](/fr/tools/image-to-prompt) sur une référence que vous aimez, puis
  ajustez la formulation.
</Tip>

## Facturation

La génération utilise **votre jeton d'activation personnel** et est
**facturée par personne**, avec un **quota mensuel** d'images. En cas
d'échec, le bouton **More details** du panneau affiche exactement ce que
le service a renvoyé.
