**Open Project** est une palette listant tous les projets dans lesquels
vous avez utilisé un agent de code — choisissez-en un pour le rouvrir dans
votre éditeur ou terminal. Fonctionne entièrement hors ligne.

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>O</kbd> depuis n'importe quelle
app.

## Fonctionnement

<Steps>
  <Step title="Ouvrez la palette">
    Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>O</kbd>. Une liste de
    **tous les projets dans lesquels vous avez utilisé Claude Code ou
    Codex** apparaît.
  </Step>
  <Step title="Choisissez un projet">
    Sélectionnez celui que vous voulez retrouver.
  </Step>
  <Step title="Choisissez comment l'ouvrir">
    Il **s'ouvre dans le terminal ou l'éditeur choisi**, soit comme une
    **nouvelle session**, soit en **reprenant votre dernière conversation**
    à cet endroit.
  </Step>
</Steps>

<Tip>
  Combinez-le avec [Frequent CLIs](/fr/tools/frequent-clis) : ouvrez le
  projet, puis passez directement à la commande avec laquelle vous
  l'exécutez.
</Tip>

## Confidentialité

Local. Construit à partir des mêmes traces d'agent sur disque
qu'utilise [Vibe History](/fr/tools/vibe-history).
