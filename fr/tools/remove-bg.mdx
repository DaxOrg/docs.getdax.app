**Remove BG** isole le sujet d'une image et le place sur fond transparent.
S'exécute entièrement sur votre Mac grâce à Apple Vision — aucun envoi,
aucune clé API, aucun réseau nécessaire.

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>D</kbd> depuis n'importe quelle
app.

## Fonctionnement

<Steps>
  <Step title="Choisissez une source">
    Choisissez **Select an Area** pour dessiner un cadre à l'écran, ou
    **Choose a File** pour ouvrir une image depuis le disque. Le choix est
    demandé à chaque utilisation.
  </Step>
  <Step title="Visualisez le détourage">
    Le sujet apparaît sur fond transparent dans un visualiseur plein écran.
    Défilez pour zoomer, glissez pour déplacer, double-cliquez pour un
    affichage 1:1.
  </Step>
  <Step title="Utilisez-le">
    Le PNG transparent est déjà dans votre presse-papiers. Il est également
    enregistré sur le Bureau et éventuellement mis en ligne pour un lien
    partageable.
  </Step>
</Steps>

## Ce que vous obtenez

- **Presse-papiers :** un PNG transparent, toujours.
- **Bureau :** enregistré sous `Cutout.png` (numéroté automatiquement si un
  fichier existe déjà). Désactivez cette option dans Settings.
- **Lien :** mis en ligne pour une URL partageable. Désactivez cette option
  dans Settings.

Un toast apparaît avec des boutons pour basculer entre copier l'image,
copier le lien ou afficher le fichier dans le Finder.

## Réglages

Settings → Tools → Remove BG :

- **Also save the cutout to the Desktop** — activé par défaut.
- **Also upload the cutout for a link** — activé par défaut. C'est la seule
  partie de l'outil qui fait sortir des données de votre Mac.

## Confidentialité

Tout s'exécute sur l'appareil grâce à macOS Vision. Aucune donnée d'image
ne quitte jamais votre Mac sauf si vous activez l'option de mise en ligne
pour un lien.
