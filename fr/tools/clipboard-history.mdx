**Clipboard History** conserve un historique consultable de tout ce que vous
copiez (texte, images et fichiers) pour que vous puissiez retrouver
n'importe quel élément d'une simple touche. Fonctionne uniquement sur
l'appareil.

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>C</kbd> depuis n'importe quelle
app.

## Fonctionnement

<Steps>
  <Step title="Copiez comme d'habitude">
    Chaque fois que vous copiez (⌘C), Dax enregistre silencieusement
    l'élément dans votre historique local.
  </Step>
  <Step title="Ouvrez la palette">
    Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>C</kbd>. Vos copies récentes
    apparaissent dans une liste consultable avec un aperçu complet de
    l'élément sélectionné.
  </Step>
  <Step title="Recollez">
    Appuyez sur <kbd>↩</kbd> pour remettre l'élément sélectionné dans votre
    presse-papiers, prêt à coller où vous en avez besoin.
  </Step>
</Steps>

## Indicateur de copie discret

Quand quelque chose est copié, l'icône de la barre de menu devient
brièvement une flèche vers le bas au lieu de jouer un son. Le signal sonore
est désactivé par défaut ; réactivez-le dans **Settings → Tools → Clipboard
History** si vous le préférez.

## Astuces

- Votre historique de presse-papiers reste entièrement sur votre Mac. Rien
  n'est envoyé.
- Texte, images et fichiers sont tous pris en charge.
- Les copies que les gestionnaires de mots de passe marquent comme masquées
  ne sont jamais enregistrées.
- Tapez pour rechercher parmi tous les éléments copiés.
- Configurez la taille de l'historique dans **Settings → Tools → Clipboard
  History**.
