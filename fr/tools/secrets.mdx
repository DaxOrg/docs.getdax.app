title: "Secrets"
description: "Partagez une clé API ou un mot de passe avec un agent de code sans jamais le coller dans la conversation."

**Secrets** vous permet de transmettre une clé API ou un mot de passe à un
agent de code **sans jamais coller la valeur dans la conversation**. Vous
enregistrez le secret une seule fois ; Dax fournit à l'agent une instruction
d'une ligne et n'injecte la vraie valeur que dans la commande qui en a
besoin, après votre approbation. Fonctionne entièrement hors ligne.

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>V</kbd> depuis n'importe quelle
app.

## Fonctionnement

<Steps>
  <Step title="Ouvrez la palette">
    Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>V</kbd>. La palette Secrets
    apparaît.
  </Step>
  <Step title="Ajoutez un secret">
    Donnez-lui un **nom** (avec autocomplétion pour les noms courants) et la
    **valeur**. La valeur est stockée dans le **Trousseau** de votre Mac ;
    vous pouvez l'afficher ou la masquer dans le champ.
  </Step>
  <Step title="Collez l'instruction">
    Dax vous fournit une **ligne prête à coller** pour l'agent, comme
    `dax run --secret OPENAI_API_KEY -- <votre commande>`.
  </Step>
  <Step title="Approuvez l'injection">
    Quand l'agent exécute cette commande, le **broker local de Dax** vous
    demande d'**approuver**. Approuvez et la vraie valeur est injectée dans
    l'environnement de *cette commande* uniquement, jamais affichée, jamais
    stockée dans le chat.
  </Step>
</Steps>

<Tip>
  **Pourquoi c'est sûr.** La valeur réside dans le Trousseau et n'est
  transmise qu'à une seule commande exécutée via le broker, uniquement sur
  votre approbation explicite. Elle n'apparaît jamais dans la conversation,
  le défilement du terminal, ni aucun journal.
</Tip>

## Confidentialité

Entièrement local. Le broker s'exécute sur votre Mac ; les secrets ne le
quittent jamais.
