**Boilerplates** crée un nouveau projet à partir d'un modèle en une seule
étape, sans cloner de dépôt, sans chercher-remplacer. Fonctionne
entièrement hors ligne.

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>N</kbd> depuis n'importe quelle
app.

## Fonctionnement

<Steps>
  <Step title="Ouvrez le sélecteur">
    Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>N</kbd>. Vos modèles
    apparaissent sous forme de tuiles.
  </Step>
  <Step title="Nommez votre projet">
    Choisissez un modèle, nommez le projet, et appuyez sur <kbd>↩</kbd>.
  </Step>
  <Step title="Commencez à construire">
    Le dossier est créé dans votre **répertoire Workspace**, et chaque
    occurrence de `__PROJECT_NAME__` (dans les noms de fichiers *et* leur
    contenu) est remplacée par le nom de votre projet. Il est prêt à
    ouvrir dans votre éditeur avec votre commande [Open
    Project](/fr/tools/open-project).
  </Step>
</Steps>

## Modèles

- Trois modèles de départ sont inclus : **iOS**, **Android**, **Vite
  React**.
- **N'importe quel dossier** que vous placez dans le répertoire des
  modèles devient lui aussi un modèle. Un modèle n'est qu'un dossier de
  fichiers ; `__PROJECT_NAME__` est le seul mot-clé spécial. Gérez-les
  (ajouter, afficher dans le Finder, supprimer) dans Settings → Tools →
  Boilerplates.
