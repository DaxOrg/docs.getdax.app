**AI Text Transform** réécrit le texte sélectionné n'importe où.
Il l'améliore, le raccourcit, corrige sa grammaire, ou applique votre propre
instruction, et remet le résultat exactement à sa place.

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>\\</kbd> depuis n'importe
quelle app.

## Fonctionnement

<Steps>
  <Step title="Sélectionnez du texte">
    Sélectionnez du texte dans n'importe quelle app.
  </Step>
  <Step title="Appuyez sur le raccourci">
    Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>\\</kbd>. Un petit menu de
    transformations apparaît.
  </Step>
  <Step title="Choisissez une transformation">
    Choisissez-en une (ou **Custom Prompt** pour écrire votre propre
    instruction). Le résultat **remplace votre sélection** ou **atterrit
    dans votre presse-papiers**, selon votre réglage.
  </Step>
</Steps>

## Transformations intégrées

- **Write this better** (améliorer)
- **Enhance Prompt :** affine un prompt pour un modèle d'IA
- **Shorten Text** (raccourcir)
- **Fix grammar** (corriger la grammaire)
- **Custom Prompt... :** tapez n'importe quelle instruction sur le moment

<Tip>
  Très utile sur les messages de commit et les descriptions de PR :
  sélectionnez un brouillon et demandez une version plus claire et plus
  concise.
</Tip>

## Options

Settings → Tools → AI Text Transform :

- **Une fois terminé :** *remplacer la sélection* ou *copier dans le
  presse-papiers*.
