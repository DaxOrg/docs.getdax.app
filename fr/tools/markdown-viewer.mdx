**Visionneuse Markdown** ouvre les fichiers `.md` avec le parser et le moteur de rendu propres à Dax — tableaux, listes imbriquées, listes de tâches, citations, notes de bas de page et blocs de code s'affichent exactement comme le document le prévoit. Vous pouvez modifier et enregistrer dans la même fenêtre.

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>R</kbd> depuis n'importe quelle app.

## Comment ça marche

<Steps>
  <Step title="Choisir un fichier">
    Sélectionnez un fichier `.md` dans le sélecteur de fichiers ou ouvrez-en un depuis le Finder.
  </Step>
  <Step title="Lire">
    Le document est rendu avec un support Markdown complet : titres, listes, tableaux, blocs de code (coloration syntaxique), images, vidéo, citations, notes de bas de page et listes de tâches.
  </Step>
  <Step title="Modifier">
    Modifiez le document et enregistrez. La visionneuse est un espace de travail, pas un aperçu en lecture seule.
  </Step>
</Steps>

## Coup d'œil

Dax inclut une extension Coup d'œil. Appuyez sur **Espace** sur n'importe quel fichier `.md` dans le Finder pour obtenir la même vue rendue.

## Confidentialité

Tout fonctionne sur votre Mac. Le contenu des fichiers ne quitte jamais l'appareil.
