**Inject MD** dépose un fichier d'instructions Markdown (comme
`AGENTS.md`) dans n'importe quel projet sur lequel vous avez travaillé,
exactement là où l'agent de code ira le lire. Fonctionne entièrement hors
ligne.

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>A</kbd> depuis n'importe quelle
app.

## Fonctionnement

<Steps>
  <Step title="Choisissez le fichier">
    Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>A</kbd>, puis choisissez
    quel fichier Markdown injecter (`AGENTS.md` par défaut).
  </Step>
  <Step title="Choisissez un projet">
    Une palette listant **tous les projets dans lesquels vous avez utilisé
    Claude Code ou Codex** apparaît, construite à partir de vos traces de
    session.
  </Step>
  <Step title="Injectez">
    Choisissez un projet. Le fichier est **écrit dans le dossier de ce
    projet**, exactement là où l'agent le cherche.
  </Step>
</Steps>

## Partager sous forme de lien

Au lieu d'injecter dans un dossier local, choisissez **Share as a link**
en haut de la palette de projets. Le fichier est mis en ligne et vous
obtenez une URL que n'importe quel agent distant (ou serveur Herdr) peut
récupérer avec `curl`.

- **Expiration :** les liens expirent après une durée définie (7 jours par
  défaut, configurable jusqu'à 30 jours).
- **Gérer les liens :** consultez et révoquez les liens publiés depuis le
  même écran.

<Tip>
  PRD Maker utilise aussi cette infrastructure de liens pour partager les
  PRD finalisés avec des agents distants.
</Tip>

## Confidentialité

Local par défaut. La liste des projets provient de traces sur disque ; le
fichier est écrit localement. Le partage sous forme de lien est la seule
action qui envoie le fichier hors de votre Mac.
