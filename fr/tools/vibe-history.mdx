**Vibe History** est une palette listant vos conversations récentes avec
Claude Code et Codex, lues directement depuis leurs fichiers de trace sur
disque. Choisissez-en une et reprenez-la.

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>S</kbd> depuis n'importe quelle
app.

## Fonctionnement

<Steps>
  <Step title="Ouvrez la palette">
    Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>S</kbd>. Vos conversations
    récentes avec les agents apparaissent sous forme de liste.
  </Step>
  <Step title="Choisissez une conversation">
    Choisissez celle que vous voulez reprendre.
  </Step>
  <Step title="Reprenez-la">
    La **commande de reprise** de cette conversation est **saisie dans le
    terminal où vous étiez**, pour vous remettre exactement où vous en
    étiez.
  </Step>
</Steps>

## Options

Settings → Tools → Vibe History :

- Choisissez quels agents inclure : **Claude Code**, **Codex**.

## Confidentialité

Local. L'outil lit les fichiers de trace que les agents écrivent déjà sur
votre Mac ; rien n'est envoyé nulle part.
