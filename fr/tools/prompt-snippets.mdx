**Prompt Snippets** vous offre une palette de prompts enregistrés et
consultables, des blocs réutilisables que vous tapez ou collez dans
n'importe quelle app d'une simple touche. Fonctionne uniquement sur
l'appareil.

  <img src="/images/screenshots/prompt-snippets.jpg" alt="Prompt Snippets" style="width: 100%; height: auto; border-radius: 12px;" />
</Frame>

## Comment l'ouvrir

Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>J</kbd> depuis n'importe quelle
app.

## Fonctionnement

<Steps>
  <Step title="Ouvrez la palette">
    Appuyez sur <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>J</kbd>. Vos snippets
    enregistrés apparaissent dans une liste consultable.
  </Step>
  <Step title="Recherchez et choisissez">
    Tapez pour filtrer, puis appuyez sur <kbd>↩</kbd> pour utiliser le
    snippet sélectionné. <kbd>⇥</kbd> bascule entre le copier dans le
    presse-papiers et le taper directement dans votre app active.
  </Step>
  <Step title="Gérez vos snippets">
    Ajoutez, modifiez ou supprimez des snippets dans **Settings → Tools →
    Prompt Snippets**. Dax est livré avec un ensemble de snippets intégrés
    pour vous aider à démarrer.
  </Step>
</Steps>

## Bibliothèque de snippets

Au-delà de vos propres snippets enregistrés, vous pouvez parcourir une
**bibliothèque organisée** de prompts préparés par l'équipe Dax. Recherchez
dans la bibliothèque depuis la palette pour trouver des prompts pour les
tâches courantes — revues de code, débogage, rédaction, brainstorming et
plus encore. Choisissez-en un et il est prêt à coller.

## Astuces

- Les snippets restent entièrement sur votre Mac. Rien n'est envoyé à un
  serveur.
- Utilisez les snippets pour des system prompts, des checklists de revue de
  code, des modèles de commit, ou tout bloc de texte que vous utilisez
  régulièrement.
- Le basculement <kbd>⇥</kbd> mémorise votre dernier choix par session.
