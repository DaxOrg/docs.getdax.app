**Prompt Snippets** te da una paleta de búsqueda con prompts guardados,
bloques reutilizables que escribes o pegas en cualquier app con una
pulsación de tecla. Solo en dispositivo.

  <img src="/images/screenshots/prompt-snippets.jpg" alt="Prompt Snippets" style="width: 100%; height: auto; border-radius: 12px;" />
</Frame>

## Cómo abrirlo

Pulsa <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>J</kbd> desde cualquier app.

## Cómo funciona

<Steps>
  <Step title="Abre la paleta">
    Pulsa <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>J</kbd>. Tus snippets guardados
    aparecen flotando en una lista con búsqueda.
  </Step>
  <Step title="Busca y elige">
    Escribe para filtrar, luego pulsa <kbd>↩</kbd> para usar el snippet
    seleccionado. <kbd>⇥</kbd> alterna entre copiarlo al portapapeles y
    escribirlo directamente en tu app enfocada.
  </Step>
  <Step title="Gestiona snippets">
    Añade, edita o elimina snippets en **Settings → Tools → Prompt
    Snippets**. Dax incluye un conjunto de snippets predefinidos para que
    empieces.
  </Step>
</Steps>

## Snippet Library

Además de tus propios snippets guardados, puedes explorar una **biblioteca
curada** de prompts creada por el equipo de Dax. Busca en la biblioteca
desde dentro de la paleta para encontrar prompts para tareas comunes:
revisiones de código, depuración, escritura, lluvia de ideas y más. Elige
uno y estará listo para pegar.

## Consejos

- Los snippets se quedan completamente en tu Mac. Nada se envía a ningún
  servidor.
- Usa snippets para system prompts, listas de revisión de código, plantillas
  de commits o cualquier bloque de texto que uses repetidamente.
- El toggle de <kbd>⇥</kbd> recuerda tu última elección por sesión.
