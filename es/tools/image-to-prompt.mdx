**Image to Prompt** (internamente, *Promptify*) convierte una imagen en un
prompt de texto detallado que puedes usar en un generador de imágenes o un
LLM para recrearla.

## Cómo abrirlo

Pulsa <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>P</kbd> desde cualquier app.

## Cómo funciona

<Steps>
  <Step title="Copia una imagen">
    Copia cualquier imagen: un diseño, una captura de pantalla, cualquier
    cosa que quieras reproducir.
  </Step>
  <Step title="Pulsa el atajo">
    Pulsa <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>P</kbd>. La imagen se envía a un
    **modelo de visión** junto con el estilo de prompt que elijas.
  </Step>
  <Step title="Pega el prompt">
    Un prompt de recreación detallado **llega a tu portapapeles** y aparece
    en un panel. Pégalo en cualquier generador de imágenes o LLM.
  </Step>
</Steps>

## Estilos de prompt

Settings → Tools → Image to Prompt:

- **UI Focused**: un prompt para reconstruir la pantalla en código.
- **General Purpose**: una descripción equilibrada y fiel.
- **Image Focused**: orientado a recrear la imagen en un modelo de imagen.
- **Ask me every time**: elige el estilo desde un menú en cada ejecución.

<Tip>
  Combínalo con [Generate Image](/es/tools/generate-image): describe una
  imagen que te guste y luego experimenta con ese prompt para crear
  variaciones.
</Tip>

## Por qué una pulsación de tecla, no un vigía

Image to Prompt se activa deliberadamente con un atajo en lugar de vigilar
tu portapapeles, así las imágenes solo salen de tu equipo con una pulsación
explícita.
