## 2.34.0

<sub>August 2026</sub>

**Herdr: adding a server tells you what happened**
- **Test is in the server dialog now**, next to Done. It shows the actual connection log — which address answered, which key was offered, what the server accepted — with a Copy button for the whole thing.
- **Pasted addresses just work.** Text copied from a cloud console often carries invisible characters (non-breaking spaces, zero-width spaces) that ssh refuses. Dax strips them automatically, and a server already saved with one starts working on the next try.
- **Downloaded key files just work.** A `.pem` from AWS arrives readable by everyone on the Mac, which ssh won't touch. Dax narrows it to owner-only for you.
- **When something is genuinely wrong, the message names it** — the field to look at, or the file and the one command that fixes it.

## 2.33.0

<sub>August 2026</sub>

**Herdr on a server** (<kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>.</kbd>)
- **Connect a server over SSH and the herd runs there.** Same window, same tabs, same agents, running on the machine with the repo, the RAM and the uptime. Add a host in Settings → Herdr → Servers and pick it from the switcher.
- **Tabs.** <kbd>⌘</kbd><kbd>T</kbd> for a tab, <kbd>⌘</kbd><kbd>N</kbd> for an agent, <kbd>⌃</kbd><kbd>Tab</kbd> to walk the bar, <kbd>⌘</kbd><kbd>W</kbd> to close an agent. Name a tab while you still remember what it was for.
- **Remote Panel.** The server behind the herd, in five tabs: Coding Agents (with one-click update), Services & Ports, Web Servers & SSL, Usage and Utilities.

**New: PRD Maker** (<kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>E</kbd>)
- Say what you want to make and get the brief for it: a composer to start from, three ways to be asked, answers you can go back into, and a document with no holes in it.

**New: Remove BG** (<kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>D</kbd>)
- The subject and nothing else. Snip or pick a picture, look at the cutout, and leave with the image or a link to it. Runs entirely on-device.

**Ask AI**
- **Web search and Deep Research.** A globe for a quick web search, a magnifier for a cited Deep Research answer that reads multiple sources.
- **Markdown rendered.** Headings, lists, code blocks with a copy button.
- **Drag the panel** by the grip. Click any attached image to open it full size.

**File Drop**
- **Shake to drop.** Pick up a file, wiggle it, and a drop shelf appears under the pointer. Drop on it and the upload starts immediately.

**Your first five minutes**
- An interactive demo that walks you to your first badge. Badges arrive as a card with a lap of light and some confetti, and belong to your account, not the Mac.

**Keeping the Mac awake**
- Close the lid and keep working. One switch in Settings, a helper that installs itself.

**Also**
- **Coding agents, found and installed for you.** Settings → Agents shows which CLIs are on this Mac and offers the ones that aren't.
- **Appearance pane** with launcher blur.
- **One Dax at a time** — a second copy hands the window back to the one already running.
- Inject MD can share a file as a link to a remote agent.
- **Fanout has been retired**; saved profiles carry over to Herdr projects.

## 2.32.0

<sub>August 2026</sub>

**New: Herdr** (<kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>.</kbd>)
- **Mission control for coding agents.** Connect a folder and Herdr opens a window of live terminals (Claude Code, Codex, Gemini, whichever you use) running side by side in the same project. Add an agent from a menu; you never open a raw shell.
- **Split by dragging.** Drag a pane against the edge of another and the space divides. Even Out Terminals squares up the seams without restarting anything.
- **A tree that tells you what's running.** Groups hold agents, agents show their brand and say when they're working. Rename, close, collapse, reorder.

**New: Clip to Link** (<kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>;</kbd>)

- **GIFs that move at the speed they were recorded.** Clips have sound (MOV), and MOV shows its size before you send it.

**A home screen**
- **Somewhere to land.** The Dock icon opens a page with your photo, your name, and the three keys worth knowing.
- **A shelf of badges** that fills up as you use Dax. Click one for its page, or the tail of the stack for the whole trophy case.

**Achievements**
- Points, streaks, and badges, earned by using tools. Levels from Newcomer to Legend, milestones like Century and Night Owl, and mastery coins (bronze, silver, gold) per tool.
- Progress syncs with your account so a reinstall or a second Mac doesn't start you over.

**Notifications**
- **Do Not Disturb** (<kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>Z</kbd>): silence every toast without leaving what you're doing.
- **Toasts go to Notification Centre** and can be answered from there.
- **Hovering a toast holds it still.**

**Also**
- Logging out takes the session with it; every signed-in window closes.
- Server faults now say so in a sentence and retry once quietly.
- Snips photograph the screen before the menu can close.
- Annotate has a blur tool and opens behind a scrim that tells you ⌘↩ sends.
- Settings closes on Escape. Palettes have a Back button.

## 2.23.0

<sub>July 2026</sub>

A new local tool for your shell history, plus stickier answer dialogs.

**New: Command History** (<kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>Y</kbd>)
- **Every command you've run, fuzzy-searchable.** Reads your shell history (zsh, bash, fish, sh, ksh, tcsh), 100% local and read-only. Nothing ever leaves your Mac. The commands you use most lead before you type a thing.
- **Pick what <kbd>↩</kbd> does, live.** A toggle in the palette (or <kbd>⌘</kbd><kbd>T</kbd>) switches between **Insert** into the focused terminal, open in a **New Terminal**, or **Copy**, remembered between sessions. <kbd>⌘</kbd><kbd>↩</kbd> inserts and runs; <kbd>⌘</kbd><kbd>C</kbd> always copies.
- **Tune what shows.** A "Start with" prefix seeds the search bar (backspace it to widen), an exclude list hides throwaway commands (ls, cd, clear...), and a filter regex keeps only real *command + arguments* lines by default. Near-duplicates are merged.
- **Safe by default.** Destructive-looking commands (rm -rf, sudo, dd...) are inserted for review but never auto-run.

**Stickier answers**
- **Ask AI & Image Ask stay open** until you close them (<kbd>esc</kbd> or the close button). No more losing an answer to a stray click.

**Polish**
- Signed, notarized, universal (Apple Silicon & Intel), macOS 14+.

- **Search bar:** <kbd>⌃</kbd> <kbd>⌥</kbd> <kbd>Space</kbd>, type to filter, and every cell is numbered: press <kbd>1</kbd>–<kbd>9</kbd> to run it. Pages of nine with an indicator when the suite outgrows one grid.

**Polish**
- Screen captures can no longer include the selection overlay or cursor pill, now excluded at the capture layer.
- Clearer onboarding (a real keycap instead of an ambiguous glyph), centered empty states, sharper project icons with tech badges.
